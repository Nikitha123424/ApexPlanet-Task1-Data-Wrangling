# Data Dictionary

| Column Name | Data Type | Description |
|-------------|----------|-------------|
| Order_ID | Text | Unique identifier for each order |
| Order_Date | Date | Date when the order was placed |
| Customer_ID | Text | Unique customer ID |
| Customer_Name | Text | Name of the customer |
| Age | Numeric | Age of the customer |
| Gender | Text | Gender of the customer |
| City | Text | City where the customer lives |
| Product | Text | Name of the product |
| Category | Text | Product category |
| Quantity | Numeric | Number of products purchased |
| Unit_Price | Decimal | Price of one product |
| Total_Sales | Decimal | Total amount of the order |
